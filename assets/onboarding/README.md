# Welcome tour screenshots

Images shown in the first-launch welcome tour (`lib/features/onboarding/onboarding_page.dart`).
Until a file exists, the tour shows an icon illustration instead.

| File | Tour step |
| --- | --- |
| `tour-editor.gif` | Write in Markdown — editor and live preview |
| `tour-run-code.png` | Run code where you write it — code block with its output |
| `tour-organize.png` | Keep everything organised — notes overview with notebooks and tags |
| `tour-tasks.png` | Plan with tasks and reminders — task dashboard or calendar |
| `tour-ai.png` | Ask the AI assistant — AI panel next to a note |
| `tour-search.png` | Find anything in seconds — command palette search |

**Format:** PNG (the editor step is an animated GIF), ideally 16:10 such as 1600 × 1000 px. Images are shown whole, never cropped; other proportions get neutral side bars. Smaller files keep the app download light.
